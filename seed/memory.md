# Durable workspace facts

Record here only facts verified in this workspace that later runs would otherwise have to rediscover: exact paths, key/column joins, units, naming conventions, and which of several look-alike values actually satisfies a requirement.

Label each fact as workspace-specific, for example: "In this workspace, role `HR` in `roles.csv` maps to position `HR Manager`; `Manager` has no open requisition."

Do not put task answers, guesses, or transient notes here.
